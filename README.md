# Expense Tracker Full Stack Web Application 💸

A modern full-stack Expense Tracker web application built using Node.js, Express.js, MySQL, HTML, CSS, and JavaScript. The application allows users to securely register, login, and manage their personal expenses with authentication and user-specific data handling.

---

# 🚀 Features

* User Registration & Login System
* JWT Authentication
* Password Encryption using bcrypt
* Protected Dashboard Routes
* Add Expenses
* Delete Expenses
* User-Specific Expense Data
* Responsive Modern UI
* Logout System
* MySQL Database Integration
* REST API Architecture

# 🏗️ How the Project Works

1. Users can register an account securely.
2. Passwords are encrypted using bcrypt before storing in MySQL.
3. Users login and receive a JWT authentication token.
4. Token is stored in browser localStorage.
5. Protected routes verify logged-in users.
6. Expenses are linked to specific users using user_id.
7. Users can add and delete only their own expenses.
8. Frontend dynamically fetches and displays expense data.
